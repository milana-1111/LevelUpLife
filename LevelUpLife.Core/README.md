# Level Up Life

Десктопный трекер привычек с системой опыта (XP), уровнями и общей таблицей лидеров.
Курсовой проект по МДК 01.01 «Разработка программных модулей», специальность 09.02.07, ГАПОУ ОКЭИ.

## Стек

C#, .NET, WPF, XAML, MVVM, Entity Framework Core, SQLite, xUnit, Git.

## Структура решения

| Проект | Назначение |
|---|---|
| `LevelUpLife.Core` | Модели предметной области, перечисления, бизнес-логика |
| `LevelUpLife` | WPF-приложение: окна (View) и ViewModel |
| `LevelUpLife.Tests` | Модульные тесты (xUnit) |

## Основные возможности

- регистрация и вход, сохранение сессии;
- создание, редактирование и удаление привычек;
- отметка выполнения за день, начисление XP и уровней;
- общая таблица лидеров;
- окно «О программе» (открывается через меню).
