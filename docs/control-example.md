# Контрольный пример

Сценарий проверяет основную цепочку: регистрация → привычки → опыт → уровень → рейтинг.

**Исходные данные.** Пустая база. Игрок «Милана» (логин `milana`, пароль `secret1`).

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Регистрация игрока «Милана» | Уровень 1, опыт 0 |
| 2 | Привычка «Зарядка», категория «Спорт», сложность «Лёгкая», все дни | В списке, состояние «Активна» |
| 3 | Привычка «Учить C#», категория «Учёба», сложность «Сложная», все дни | В списке, состояние «Активна» |
| 4 | Отметить «Зарядка» | +10 XP, всего 10, уровень 1 |
| 5 | Отметить «Учить C#» | +30 XP, всего 40, уровень 1 |
| 6 | Повторно выбрать «Зарядка» | Кнопка «Выполнено» недоступна |
| 7 | Зарегистрировать игрока «Борис», выполнить «Лёгкую» привычку | У Бориса 10 XP |
| 8 | Рейтинг → Таблица лидеров под Борисом | 1-е место Милана (40 XP), 2-е Борис (10 XP), «Ваше место: 2» |
| 9 | Перезапустить приложение | Открывается главное окно Бориса без ввода пароля |

**Таблица опыта и уровней.**

| Уровень | Нужно XP |
|---|---|
| 1 | 0 |
| 2 | 100 |
| 3 | 300 |
| 4 | 600 |
| 5 | 1000 |

За выполнение: лёгкая привычка 10 XP, средняя 20 XP, сложная 30 XP.
