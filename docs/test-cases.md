# Пользовательские тест-кейсы

| № | Что проверяем | Шаги | Ожидаемый результат |
|---|---|---|---|
| 1 | Регистрация | В окне входа нажать «Нет аккаунта? Зарегистрироваться», ввести логин `milana`, пароль `secret1`, имя «Милана», нажать «Зарегистрироваться» | Открывается главное окно, показано имя «Милана», уровень 1 |
| 2 | Проверка логина | Зарегистрироваться с логином `ab` | Сообщение: логин должен содержать от 3 до 30 символов |
| 3 | Проверка пароля | Зарегистрироваться с паролем `123` | Сообщение: пароль должен содержать от 6 до 64 символов |
| 4 | Повторный логин | Зарегистрироваться с уже существующим логином | Сообщение: пользователь с таким логином уже существует |
| 5 | Вход | Выйти из аккаунта (Файл → Выйти), войти с верными данными | Открывается главное окно |
| 6 | Неверный пароль | Войти с неверным паролем | Сообщение: неверный логин или пароль, окно не закрывается |
| 7 | Сохранение сессии | Закрыть приложение и запустить снова | Сразу открывается главное окно, вводить пароль не нужно |
| 8 | Выход из аккаунта | Файл → Выйти из аккаунта, затем перезапустить приложение | Открывается окно входа |
| 9 | Добавление привычки | Привычки → Добавить, ввести «Утренняя зарядка», категория «Спорт», сложность «Лёгкая», все дни, «Сохранить» | Привычка появилась в списке со статусом «Активна» |
| 10 | Проверка названия | Добавить привычку с названием из 2 символов | Сообщение: название должно содержать от 3 до 100 символов, окно не закрывается |
| 11 | Проверка дней | Снять все флажки дней недели и сохранить | Сообщение: выберите хотя бы один день недели |
| 12 | Отметка выполнения | Выбрать привычку, нажать «Выполнено» | Статус «Выполнена», +10 XP, шкала опыта выросла, в строке состояния сообщение |
| 13 | Повторная отметка | Выбрать выполненную привычку | Кнопка «Выполнено» недоступна |
| 14 | Повышение уровня | Выполнять привычки, пока опыт не достигнет 100 XP | Сообщение «Новый уровень: 2!», уровень в заголовке обновился |
| 15 | Пропуск | Выбрать активную привычку, нажать «Пропустить» | Статус «Пропущена», опыт не начислен, отметить выполненной уже нельзя |
| 16 | Изменение привычки | Выбрать привычку, «Изменить», сменить сложность на «Сложная», сохранить | В списке новая сложность, поля формы были заполнены текущими данными |
| 17 | Удаление привычки | Выбрать привычку, «Удалить», подтвердить | Привычка исчезла из списка. При ответе «Нет» привычка остаётся |
| 18 | Привычки не на сегодня | Создать привычку только на завтрашний день недели | В обычном списке её нет. С флажком «Показывать все привычки» есть со статусом «Не сегодня», отметить её нельзя |
| 19 | Таблица лидеров | Зарегистрировать второго игрока, набрать разный опыт, Рейтинг → Таблица лидеров | Игроки по убыванию опыта, внизу или вверху «Ваше место: N» |
| 20 | Окно «О программе» | Справка → О программе | Показаны тема проекта, исполнитель и учебное заведение, окно закрывается по «ОК» и Esc |
| 21 | Меню | Открыть все пункты меню | Все пункты работают, недоступные пункты (например, «Изменить» без выбора) неактивны |
| 22 | Восстановление состояния | Добавить привычки, отметить одну, закрыть и открыть приложение | Все привычки и отметки на месте |
