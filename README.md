# Level Up Life

Десктопный трекер привычек с системой опыта (XP), уровнями и таблицей лидеров.
Курсовой проект по МДК 01.01 «Разработка программных модулей», специальность 09.02.07, ГАПОУ ОКЭИ.

## Стек

C#, .NET, WPF, XAML, MVVM, Entity Framework Core, SQLite, Dependency Injection, Serilog, xUnit, Git.

## Структура решения

| Проект | Назначение |
|---|---|
| `LevelUpLife.Core` | Модели, перечисления, расчёт XP, проверка ввода, состояния, сервисы, контекст БД |
| `LevelUpLife` | WPF-приложение: окна (View), ViewModel, внедрение зависимостей |
| `LevelUpLife.Tests` | Модульные тесты (xUnit) |

## Архитектура

- **MVVM**: окна ничего не знают о данных, вся логика в ViewModel и сервисах.
- **Паттерн «Состояние»** (`Core/States`): статус привычки за день (Активна, Выполнена, Пропущена). Каждое состояние само решает, какие переходы разрешены.
- **Паттерн «Фасад»** (`HabitService`): единая точка работы с привычками. Прячет за собой базу данных, расчёт XP, проверку ввода и состояния.
- **SOLID**: зависимости передаются через интерфейсы (`IAuthService`, `IHabitService`, `ILeaderboardService`, `IWindowService`) и внедряются контейнером DI.

## Возможности

- регистрация, вход, сохранение сессии между запусками;
- создание, изменение и удаление привычек (категория, сложность, дни недели);
- отметка выполнения за день, начисление XP и уровней;
- таблица лидеров;
- окно «О программе», управление через меню;
- проверка вводимых данных, журнал ошибок, перехват необработанных исключений.

## Где хранятся данные

В папке `%LocalAppData%\LevelUpLife`: база `levelup.db`, токен сессии `session.token`, логи в папке `logs`.
